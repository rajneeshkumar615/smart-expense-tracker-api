# AI Notes

This document is transparent about how AI assistance was used in building this project.

## What AI generated

- **AI generated project structure**: The overall folder layout (routes / controllers / services / middleware / utils / data / tests) was generated by AI, following a standard layered Node.js/Express architecture.
- **AI generated initial CRUD implementation**: The initial implementation of all endpoints (`POST /api/expenses`, `GET /api/expenses`, `GET /api/expenses/total`, `DELETE /api/expenses/:id`), the JSON file storage utility, validation logic, centralized error handling middleware, and the Jest/Supertest test suite were generated by AI.

## What was manually verified

- **I manually tested every endpoint** using curl/Postman against a running instance of the server, confirming correct status codes and response shapes for create, list, filter, total, and delete operations.
- **I verified validation** for all required fields (`title`, `category`, `amount`, `date`), including edge cases such as empty strings, non-numeric amounts, zero/negative amounts, and invalid date strings.
- **I fixed any issues found during testing**, including:
  - Ensuring the `/api/expenses/total` route is registered before the `/api/expenses/:id`-style routes so it isn't accidentally matched as an `:id` parameter.
  - Making category filtering case-insensitive so `?category=food` and `?category=Food` behave the same way.
  - Rounding total calculations to 2 decimal places to avoid floating-point precision artifacts (e.g. `0.1 + 0.2`).
  - Ensuring the JSON data file is created automatically if it doesn't exist, so the app runs immediately after a fresh clone.
  - Confirming the centralized error handler correctly returns 400 for validation errors, 404 for not-found resources and unknown routes, and 500 for unexpected errors, without leaking stack traces to the client.

## Notes on testing environment

Automated `npm test` runs reset `src/data/expenses.json` before and after the suite to keep tests deterministic and isolated from any real data used during manual testing.
